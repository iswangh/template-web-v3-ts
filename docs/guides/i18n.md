# 国际化（vue-i18n）

项目使用 [vue-i18n](https://vue-i18n.intlify.dev/) v11，Composition API 模式（`legacy: false`）。

## 目录结构

```
src/
├── config/i18n.ts      # 默认语言类型与常量
├── i18n/index.ts       # createAppI18n() 工厂
├── locales/
│   ├── zh-CN.ts        # 简体中文
│   └── en-US.ts        # 英文
└── main.ts             # app.use(createAppI18n())
```

## 切换默认语言

修改 `src/config/i18n.ts`：

```typescript
export type AppLocale = 'zh-CN' | 'en-US'
export const defaultLocale: AppLocale = 'zh-CN'  // 改此处
```

## 添加语言包

1. 在 `src/locales/` 新建文件（如 `ja-JP.ts`）
2. 扩展 `AppLocale` 类型
3. 在 `src/i18n/index.ts` 的 `messages` 中注册

## 在组件中使用

`vue-i18n` 已通过 unplugin-auto-import 自动导入，可直接使用：

```vue
<script setup lang="ts">
const { t, locale } = useI18n()

function switchLang() {
  locale.value = locale.value === 'zh-CN' ? 'en-US' : 'zh-CN'
}
</script>

<template>
  <p>{{ t('common.welcome') }}</p>
</template>
```

## 语言包组织

当前采用扁平 namespace 结构：

```typescript
// src/locales/zh-CN.ts
export default {
  common: {
    welcome: '欢迎',
  },
}
```

业务扩展时建议按模块划分 key（如 `auth.login.title`），避免单文件过大。

## 开发提示

- `missingWarn` / `fallbackWarn` 仅在 DEV 环境开启，便于发现缺失翻译。
- 运行时切换语言只需修改 `locale.value`，无需重启应用。
